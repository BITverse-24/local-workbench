# Cold-room monitoring rule CR-2

- Valid operating range: 2.0°C through 5.0°C, inclusive.
- A blank temperature is a missing reading. Do not count it as zero or as an out-of-range reading.
- A numeric value below 2.0°C or above 5.0°C is out of range.
- Report counts and include each out-of-range timestamp in the incident summary.
