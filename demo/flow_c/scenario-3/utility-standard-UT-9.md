# Utility Piping Standard UT-9

## 5.1 Branch size
Hot-water branches on header DN150 must be DN50 minimum.

## 5.2 Flange class
Hot-water branch connections must use flange Class 300.

## 5.3 Construction release
Any branch that fails a minimum size or flange class requirement must be corrected before the drawing is released for construction. Assess each branch against both requirements.
