# TPL-012 — Inspection approval-note template

Document ID: `TPL-012`
Revision: `2.0`

## [section:equipment-header] Equipment

Include the equipment identifier and the inspection report reference.

## [section:findings-summary] Findings

List every validated inspection finding with its measurement, condition,
location, and page evidence where available.

## [section:recommendation] Recommendation

State the supported approval disposition and any repair or replacement needed
before return to service. Do not invent an approval date or authority.

## [section:grounding-references] Grounding references

List each retrieved SOP citation using its exact inline citation text.
