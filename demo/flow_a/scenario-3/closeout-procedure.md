# Exchanger Repair Close-out Procedure EX-22

## 7.1 Repair evidence
The work pack must identify the repaired equipment, list the installed replacement parts, and record the post-repair pressure test result.

## 7.2 Acceptance test
The hydrostatic test must reach at least 15.0 bar and show no leakage for 30 minutes. A passing test confirms the repair test only; it does not grant permission to return equipment to service.

## 7.3 Release authorization
Return to service requires both the maintenance supervisor and the plant authority to sign the release record. If either signature is missing, status is pending and the equipment must remain isolated.
