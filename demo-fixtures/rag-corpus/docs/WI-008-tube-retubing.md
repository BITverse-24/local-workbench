# WI-008 — Tube retubing work instruction

Document ID: `WI-008`
Revision: `3.3`
Status: Approved

## [section:1.0] Work scope

This work instruction describes preparation, removal, installation, and
verification of replacement tubes in a shell-and-tube exchanger. It must be
used with the equipment-specific work pack and does not replace the inspection
or approval procedure.

## [section:2.1] Identification

Before removing a tube, mark the exchanger, pass, row, and tube position on
the controlled drawing. Confirm the affected positions against the inspection
report. The work pack must list removed tubes, replacement material, tube
sheet condition, and any plugs installed as a temporary control.

## [section:3.2] Installation checks

Inspect the tube sheet and adjacent tubes for damage. Install replacement
tubes using the approved process and record expansion or weld parameters as
applicable. A visual completion check is required before pressure testing.

## [section:4.1] Return-to-service evidence

The completion record must include the final tube list, pressure-test result,
leak check, outstanding work, and reviewer. Retubing work supports a repair
disposition, but return to service still requires the applicable approval note
and completion of other recommendations such as gasket replacement.
