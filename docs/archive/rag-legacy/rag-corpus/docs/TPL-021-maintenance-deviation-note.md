# TPL-021 — Maintenance deviation note template

Document ID: `TPL-021`
Revision: `1.2`

## [section:equipment] Equipment header

Include the equipment identifier, operating unit, work order, source report
reference, and the date of the inspection or maintenance activity.

## [section:deviation] Deviation description

Describe the observed condition using only validated measurements and source
evidence. Include the location, original units, applicable limit, and page or
section reference where available. Do not convert an observation into an
approval decision.

## [section:disposition] Disposition

State the immediate control, required repair, owner, and due date when those
values are known. If authority, date, or responsibility is missing, mark the
field as missing information rather than inventing a value.

## [section:references] References

List each supporting document using its stable document identifier and exact
section identifier. Inline citations must match the retrieved source record.
