# SOP-520 — Inspection record retention

Document ID: `SOP-520`
Revision: `1.8`
Status: Approved

## [section:1.0] Purpose

This procedure defines the minimum information retained for inspection and
maintenance records. Records must remain traceable to the equipment, work
order, source evidence, and disposition. The procedure applies to reports,
attachments, approval notes, photographs, and supporting measurements.

## [section:2.1] Required identifiers

Each record must carry a stable record reference, equipment identifier,
operating unit, inspection or work date, document type, revision, and status.
When a record cites another document, the citation must preserve that
document's stable identifier and section identifier. File names may be human
readable, but they do not replace the identifiers inside the record.

## [section:3.2] Evidence and corrections

Measured values must retain their original units and the location where the
measurement was taken. Corrections must be attributable and must not erase
the original value. A replacement report must identify the superseded
revision. Generated approval notes must preserve the source report reference
and the evidence used to support their recommendation.

## [section:4.1] Review and retention

The responsible reviewer confirms that required fields are present before
the record is released. Records with missing approval authority, unresolved
findings, or unsupported conclusions remain incomplete. Retention duration is
set by the applicable records schedule; deletion must never be used to hide
an unresolved inspection result.
