# SOP-411 — Pressure relief valve testing

Document ID: `SOP-411`
Revision: `5.0`
Status: Approved

## [section:1.0] Purpose

This procedure defines how installed pressure relief valves are identified,
tested, and recorded. It applies to bench tests and approved in-situ tests.
The test record is equipment-specific and must not be reused for a different
valve or set-pressure range.

## [section:2.3] Test preparation

Confirm the valve tag, service, set pressure, test pressure range, last test
date, and calibration status of the test equipment. Verify that the current
drawings and isolation plan identify the correct valve. Any mismatch between
the valve nameplate and the work order must be resolved before testing.

## [section:3.1] Acceptance criteria

Record the first opening pressure, reseat pressure, leakage observation, and
test temperature. Compare the readings with the approved tolerance for the
valve class. A result outside tolerance is a failed test, even if the valve
later operates normally. The record must identify the disposition, such as
adjustment, repair, replacement, or engineering review.

## [section:4.2] Test report

The completed report must include the valve identifier, serial number, test
equipment identifier, calibration due date, readings, acceptance decision,
technician, reviewer, and date. A test report does not authorize return to
service when another open inspection finding prevents release.
