# REF-044 — Equipment identifier standard

Document ID: `REF-044`
Revision: `1.0`
Status: Controlled reference

## [section:1.0] Identifier structure

Equipment identifiers use the controlled tag assigned by the asset register.
The identifier is copied exactly into inspection reports, work orders,
approval notes, and generated artifacts. Do not replace a controlled tag with
an informal nickname or a shortened label.

## [section:2.1] Unit and service fields

Where a form requests an operating unit, record the unit assigned by the asset
register. Service descriptions may be added for clarity, but they do not
replace the equipment tag. A record that contains conflicting identifiers
must be held for review before it is used as approval evidence.

## [section:3.1] References in documents

Cross-document references should use the source document's stable identifier,
revision where required, and section identifier. A file name is useful for
navigation, but the identifier and section are the authoritative citation
components.
